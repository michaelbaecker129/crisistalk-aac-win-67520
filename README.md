## About CrisisTalk AAC

CrisisTalk AAC is a lightweight augmentative and alternative communication application that runs directly in a web browser. Its emergency-focused interface organizes common symptoms, needs, and quick responses so users can communicate important information during stressful situations.

The application is designed with accessibility in mind for people with speech impairments, as well as situations where clear communication with emergency personnel and first responders is important. It works as a single-file HTML application, includes multilingual support for eight languages, and can provide spoken output through the browser's Web Speech API.

---

## Features

- Fully offline, single-file HTML application with no external dependencies
- Responsive interface designed around accessibility and WCAG support
- Emergency communication categories for symptoms, needs, and rapid responses
- Interactive body map and pain scale for describing discomfort
- Eight-language communication support
- Text-to-speech output through the Web Speech API
- Dark and light display themes
- Keyboard navigation and screen reader support
- Optional Web Audio click feedback
- Local storage for remembering the selected theme

## Usage

1. Launch the HTML file in a supported web browser.
2. Select the language needed for communication.
3. Choose an emergency category, symptom, need, or quick response.
4. Use the body map or pain scale when describing physical discomfort.
5. Present the selected message or use text-to-speech when browser speech support is available.
6. Switch between light and dark themes from the interface as needed.

Keyboard navigation and screen reader support can be used to move through controls without relying exclusively on a pointer.

## Configuration

CrisisTalk AAC does not require a separate configuration file. Interface preferences are handled within the application, and the selected theme can be stored locally in the browser.

Available options include:

- Light or dark theme selection
- Language selection from the eight supported languages
- Browser text-to-speech output where the Web Speech API is available
- Web Audio click feedback where supported by the browser and device

To reset the locally stored theme preference, clear the site's local browser storage or use the browser's storage management controls for the application.

The selected light or dark theme is stored locally in the browser. It can be removed by clearing the application's local browser storage.
